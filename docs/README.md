# Documentación del Proyecto

Esta carpeta contiene documentación y archivos relacionados con el proyecto.

## Estructura

- `DEPLOYMENT.md` - Guía de deployment
- `CHECKLIST-DEPLOYMENT.md` - Checklist para deployment
- `VARIABLES-VERCEL.txt` - Variables de entorno para Vercel (desarrollo)
- `VARIABLES-VERCEL-PRODUCCION.txt` - Variables de entorno para Vercel (producción)
- `migrations/` - Archivos SQL de migraciones y esquemas

## Migraciones

Los archivos de migración SQL se encuentran en `migrations/`:
- `full_production_schema.sql` - Esquema completo de producción
- `migration-output.sql` - Salidas de migraciones ejecutadas
- `migration-data.json` - Datos de migración en formato JSON
